# 我用「氛围式编程」做了一款习惯养成小程序

人人都可以用 Vibe Coding 解决自己的需求，顺便帮到更多人。

---

我想给家里孩子做一个习惯养成小工具：每天打卡、攒星星、换奖励，在微信里用，家长能一起管。我既不是程序员，也没打算报班学开发。试了试**用自然语言和 AI 一起写代码**——Vibe Coding（氛围式编程）——才发现：**把想法说清楚，比会写语法重要得多。**

做法很简单：在 Cursor 里用中文描述我要什么，AI 帮我搭页面、接逻辑。「做一个习惯列表，每个可以打 1～5 颗星」→ 打卡页有了；「星星要能存下来、能换奖励」→ 积分和商店有了；「家长要能配置」→ 家长端和邀请码有了；「要能看历史」→ 记录页有了。我负责提需求、点真机看效果，AI 负责拆成页面和代码。就这样，「萌芽好习惯」从零变成了一款真的能在微信里用的小程序。

这段经历让我想清楚几件事：**需求清晰比技术栈重要**——说清「要什么、给谁用」，AI 才能帮你落地；**不必先变成程序员**——会描述问题、会判断对错、会点一点真机，就够开始了；**你做的工具可以帮到别人**——一开始只是自家用，做成小程序后别的家庭也能用，解决自己的需求与帮助他人可以是一件事的两面。

不必等「学完编程」再动手。从小而具体的需求开始，选熟悉的场景，用自然语言把想法写下来，和 AI 一起迭代：先跑通，再优化。Vibe Coding 是让更多人有能力把想法变成可用的东西。你解决的是自己的问题，做出来的东西很可能也能帮到和你一样需要的人。
